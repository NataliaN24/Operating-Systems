# 💻 Operating Systems — Tasks

This repository contains my solutions to **programming tasks and exercises** completed as part of the **Operating Systems** course.

The tasks focus on understanding and applying fundamental **Operating Systems concepts** through practical programming in **C** and **Bash**.

## 📚 Topics

Throughout the tasks, the following concepts are covered:

- **Process Management**
- **Process Synchronization**
- **Inter-Process Communication**
- **Pipes**
- **File Descriptors and File Operations**
- **Concurrent and Sequential Processes**
- **Signals**
- **Mutual Exclusion**
- **Synchronization Mechanisms**
- **Binary File Processing**
- **Shell Scripting**
- **Unix/Linux System Programming**

## 🛠️ Technologies

- **C**
- **Bash**
- **Linux / Unix**

## 📂 Repository Structure

Each task is organized in its own directory and contains the **source code** and any additional files required for the solution.

The repository is organized according to the tasks completed during the course, making it easy to navigate through the different exercises and topics.

## 🎯 Purpose

The main purpose of this repository is to **practice and demonstrate practical knowledge of Operating Systems concepts** and their implementation in a Unix/Linux environment.
